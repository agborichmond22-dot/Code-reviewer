## 2025-07-28 - Focus Ring Clipping & Screen Reader Toast Announcements
**Learning:** Absolute-positioned or edge-to-edge elements (such as full-pane code textareas) clip standard outer focus outline rings due to `overflow: hidden` on their parent elements. Applying a negative offset such as `outline-offset: -2px` with `:focus-visible` keeps focus indicators fully visible and visually clean inside the boundary. In addition, dynamically injected screen status elements like floating toasts are completely ignored by screen readers unless explicitly marked with `role="status"` and `aria-live="polite"`.
**Action:** For full-bleed or pane-wrapped text inputs, always implement focus indicators with a negative outline offset to avoid clipping. For any dynamic toast UI elements, always guarantee screen reader compatibility by explicitly defining polite live region roles.
