## 2024-12-18 - Keyboard Focus Ring Accessibility in Dark-Themed Web Applications
**Learning:** Suppressing browser-default outlines with `outline: none;` without providing custom visual focus indicators creates severe keyboard traps and WCAG AA accessibility violations. Using modern CSS `:focus-visible` allows targeting ONLY keyboard-navigated focus states without cluttering mouse click interactions. In custom-designed code editors and inputs, using box-shadows (especially inset styles) provides precise focus indication without disrupting absolute line gutter elements or causing page reflow.
**Action:** Always avoid `outline: none;` on interactive controls. Ensure every button, input, select, and textarea has defined `:focus-visible` rules matching the layout constraints and theme colors.
