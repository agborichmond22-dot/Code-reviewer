## 2023-11-20 - Visual Focus Indicators & Screen Reader Toasts
**Learning:** Code editor components and textareas often suppress standard browser focus outlines (`outline: none`) for visual minimalism. This completely breaks keyboard navigation and visual-tracking for assistive technology users. Restoring focused element visibility with customized, brand-integrated `:focus-visible` outline offsets provides a delightful and fully accessible navigation experience. Similarly, transient elements like toast notifications must explicitly contain `role="status"` and `aria-live="polite"` to guarantee they are announced to screen readers.
**Action:** Always check interactive code inputs and custom components to ensure they do not omit `:focus-visible` states, and always label dynamically-filled toast containers with polite ARIA live regions.
