## 2025-07-24 - [Avoid Event Parameter Collision with Default Arguments]
**Learning:** In vanilla JavaScript, registering an event listener directly to an optimized function that uses a default argument (e.g., `codeEl.addEventListener('input', updateGutter)`) causes the implicit `Event` object to be passed as the first parameter. If the function relies on checking a truthy default argument or a general parameter (e.g., `force = false`), the browser-passed `Event` will be treated as truthy, overriding the default behavior.
**Action:** When defining event-bound utility functions with conditional arguments, avoid generic checks or default parameters that can be overridden by an implicit `Event` object. Instead, explicitly check for the strict expected type or value (e.g., `force === true`).
