## 2026-07-23 - Avoiding Redundant DOM Gutter Rebuilds in Text Editors
**Learning:** In browser-based code editors or line-number views, executing O(N) array generation, string joining, and setting innerHTML on every standard keystroke is a massive performance bottleneck. Because the gutter line numbers are purely a function of the number of lines, 99% of normal keystrokes (inserting/deleting characters without changing line count) do not require any DOM changes. Guarding with a cached `lastLineCount` check completely eliminates redundant HTML parsing and browser layout/reflow calculations.
**Action:** Always cache and check previous structural state (like line count or list size) before performing costly DOM manipulations or layout updates on frequent user events (e.g., input, scroll, resize).
