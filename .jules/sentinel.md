## 2026-08-06 - Secure Client-Side API Key Storage and Transmission
**Vulnerability:** Static frontend web applications that lack a secure backend proxy must rely on users providing their own API keys. If the keys are not masked, they are vulnerable to shoulder surfing. Furthermore, omitting safety headers or omitting `try/catch` wrappers around local storage reads/writes can lead to application crashes or unauthorized data exposure in restricted environments.
**Learning:** Direct browser requests to the Anthropic Claude API require explicit acknowledgment via headers (`x-api-key`, `anthropic-version`, and `anthropic-dangerous-direct-browser-access: true`). To securely capture and handle these keys, they must be masked with password inputs and accessed safely via standard local storage wrappers.
**Prevention:** Always use password-masked inputs (`type="password"`) with `autocomplete="off"` and `spellcheck="false"`. Wrap all `localStorage` reads/writes in robust `try/catch` handlers to safeguard against privacy-mode sandbox restrictions.
